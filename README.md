## Welcome, wizard

**The Puzzle Wizards Wiki** is a guide to [Puzzle Wizards](https://store.steampowered.com/app/2344820/), the free-to-play cozy co-op MMO. It provides tips and tricks for the game's villages, adventures, items, puzzles, events and ever-growing magical world.

The site is powered by [Jekyll](https://jekyllrb.com/) and the [Chirpy theme](https://github.com/cotes2020/jekyll-theme-chirpy), giving the wiki full-text search, tags, categories, responsive pages, syntax highlighting, dark mode.

## Project structure

```text
.
├── _config.yml       Site identity and Jekyll configuration
├── _data/            Theme, contact, and sharing configuration
├── _posts/           Wiki articles written in Markdown
├── _tabs/            Top-level navigation pages
├── assets/           Images, downloads, and other static files
├── tools/            Local development and release helpers
├── Gemfile           Ruby dependencies
└── README.md          The document you are reading
```
